# Brand × Reference Adaptation

Reference DNA contributes structural logic; BrandDNA contributes identity rules. The resolver transfers principles rather than identity:

`Reference DesignDNA + BrandDNA → Compatibility Report → AdaptedDesignConstraints → Design Spec`

It never copies another logo, exact brand color, literal typography, signature device, or decorative symbol.

## Compatibility and actions

`resolveBrandReferenceCompatibility()` reports compatible and adaptable patterns, conflicts, rejected traits, required brand overrides, adaptation actions, brand drift risk, and reference imitation risk. Actions are:

- `preserve`: keep a compatible structural principle.
- `translate`: retain function or proportion using approved brand tokens.
- `reinterpret`: preserve intent through a different brand expression.
- `override`: explicit brand authority replaces a conflicting reference identity.
- `reject`: prohibited behavior or copied identity is removed.

For example, a blue reference accent becomes the approved brand-red accent while preserving coverage and focal function. A serif reference with required brand sans typography keeps scale contrast and hierarchy but replaces font identity. High-confidence asymmetry remains when no explicit brand composition rule conflicts.

## Priority and risk

The contextual priority matrix is: legal/safety/accessibility; required or forbidden brand rules; platform constraints; high-confidence reference structure; brand soft characteristics; communication objective; creative interpretation. Soft brand tendencies do not erase strong reference structure unless an explicit rule requires it.

`brandDriftRisk` increases with wrong colors/type, logo misuse, prohibited treatment, or missing distinctive assets. `referenceImitationRisk` increases with exact colors, coordinates, hero subject, graphic devices, typography, and decorative details. Preserving principles is not copying execution.

`adaptReferenceDNA()` produces compact constraints for composition, hierarchy, color, typography, spacing, shape, photography, materials, iconography, distinctive assets, anti-patterns, and actions. `buildBrandDesignContext()` sends this compact representation—not full BrandDNA—to `DesignSpecPromptBuilder`. Decision provenance distinguishes brand hard constraints, soft preferences, reference structure, communication, format, adaptation, and creative interpretation.
