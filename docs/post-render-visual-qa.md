# Post-render visual QA

Pre-render approval approves intent and structure, not pixels. Phase 10 first runs a zero-cost local audit, then reviews generated assets and the rasterized composite. Mechanical blockers stop before AI. A regeneration verdict is now resolved inside the same server request through correction, durable replacement, re-render, re-raster and compact verification. Generated projects require `visualApproved`; deterministic-only projects may be locally approved.
# Campaign families

Every rendered format retains an independent pixel QA outcome. Batched provider transport does not merge findings or approvals across variants.
