# Generated Asset Storage

Project/session records store metadata, checksum, fingerprint and an opaque `bytesRef`; they never persist base64 payloads. Generated bytes are untrusted and must pass size, media-type magic-byte and dimension checks before storage.

The current memory store is for local validation only and loses bytes on restart/cold start. A production adapter should use durable private object storage, signed delivery URLs, idempotent checksum keys and retention controls.
