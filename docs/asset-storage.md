# Generated Asset Storage

Project/session records store metadata, checksum, fingerprint and an opaque `bytesRef`; they never persist base64 payloads. Generated bytes are untrusted and must pass size, media-type magic-byte and dimension checks before storage.

The memory store is for local validation only. Production now uses Vercel Private Blob with strict content-addressed references, private temporary reads and fail-closed selection. Generated metadata includes creation time and is ready for future retention-class and last-access metadata.
