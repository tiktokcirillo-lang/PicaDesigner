# Art Direction Revision Loop

The loop is immutable and bounded to one round: local semantic layout repair, alternate eligible layout candidate, alternate eligible creative route with a newly solved layout, then targeted Terra revision only when cheaper options fail. Terra returns field/reason/newValue changes for an allowlist; it cannot rewrite copy, claims, offers, dates or logos. Revised routes must pass governance again.

Route changes require compact Sol verification; mechanical layout-only changes can be verified locally. Original sessions, critique, actions and before/after audits remain in `RevisionRound`. Budget failure yields `partial` and never fake approval.
