# Workspace design system

The interface uses centralized CSS tokens for charcoal/navy surfaces, cream text, restrained gold accent and semantic status colors. DM Sans is the UI face, Cormorant Garamond is restricted to the wordmark and DM Mono is used for technical metadata.

Reusable primitives cover buttons, icon buttons, fields, select, textarea, switch, badges, dialog, toast, skeleton, empty and error states. Focus rings, labels and named icon buttons support keyboard navigation. The desktop layout prioritizes the artboard; tablet collapses density; narrow screens retain status, preview and downloads while recommending a larger editing surface.
