# Legacy UI migration

The former 119 KB inline application was removed after its useful workflow was mapped to React: copy, tone, reference upload, brand settings, canonical formats, generation stages, render/QA, durable restore, history, preview and export.

Dead logo generation, timer-based loading, client-owned project authority, CDN production exports and global window actions were not carried forward. Diagnostics are secondary and sanitized. Existing server engines and legacy Gemini compatibility code remain untouched.
