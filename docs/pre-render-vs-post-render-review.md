# Pre-render vs Post-render Review

Pre-render review judges intent, hierarchy, composition topology, spacing, text capacity, safe areas, brand constraints, provenance and production feasibility. It cannot inspect pixels that do not exist. A future `PostRenderVisualReview` will own generated-image artifacts, physical lighting, anatomy, raster sharpness and final asset fidelity; its interface is reserved but no renderer or image generation is implemented in Phase 7.
