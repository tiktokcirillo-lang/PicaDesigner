# Meta Ads production family

The canonical `meta_ads_family` contains, in deterministic order, 1080×1080, 1080×1350, 1080×1920 and 1200×628. The default primary format is 1080×1350. It is only the solving base: all other layouts are natively reflowed with their own safe area, grid, typography and image placement.

Three approvals are a partial family. Package readiness requires all four visual authorities and continues to use `validateProductionFamily()`.
